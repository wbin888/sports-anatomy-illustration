# 运动解剖绘图规则

用于需要表达**肌肉、骨骼与关节如何产生、控制和稳定动作**的作品，包括运动解剖教学图、训练动作肌肉分工图、动作分期图、体态与功能解剖示意，以及漫画中的运动讲解页。损伤机制和康复动作另读[运动损伤与康复](sports-injury-and-rehab.md)，动作分期的具体流程见[动作分析](movement-analysis.md)。

静态解剖结构（起止点、层次、走行、神经血管关系）仍按[真实参考与证据](anatomy-reference-search.md)取证。本文件补充“动作”这一维度：同一块肌肉在不同关节角度、负荷和分期中的角色可能完全不同，画面必须说明是**哪一刻、哪一侧、哪种收缩**。

## 1. 先定动作坐标

每幅运动解剖图开始前，在脚本或 `movement-spec.json` 中写明：

| 项目 | 要求 |
|---|---|
| 解剖学姿势与参照 | 默认以解剖学姿势描述方向；非标准起始姿势（如俯卧、悬垂、单腿站）写清楚 |
| 观察平面与视角 | 矢状面（屈伸、背屈/跖屈）、冠状面（外展/内收、侧屈、内翻/外翻）、水平面（旋转、水平内收/外展、旋前/旋后）；关键动作不在当前视角可见时，加辅助视图，不靠箭头“透视”补画 |
| 侧别 | 左/右、支撑腿/摆动腿、优势侧；镜像参考图时记录 |
| 分期与时刻 | 用可观察事件界定（如“足触地”“最低点”“离地”），不用模糊的“发力时” |
| 负荷与人群 | 徒手/外负荷、速度、训练水平；研究结论只适用于其受试者范围 |

关节与动作名称使用随包 [`data/joint-actions.json`](../data/joint-actions.json) 的受控词表，中文术语采用其中的 `action_zh`。肩胛胸壁“关节”、躯干等功能单元单独列出，不与盂肱关节混写。

## 2. 肌肉角色与收缩方式

| 角色 | 画面含义 |
|---|---|
| 主动肌（agonist） | 本分期主要产生或控制目标关节动作的肌肉 |
| 协同肌（synergist） | 辅助主动肌，或抵消主动肌不需要的副作用 |
| 拮抗肌（antagonist） | 产生相反动作；可在减速、关节保护或共同收缩中出现，不等于“放松” |
| 稳定肌（stabilizer） | 主要维持近端或躯干位置，常为等长收缩 |

| 收缩 | 关系 | 推荐视觉编码 |
|---|---|---|
| 向心（concentric） | 肌肉产生的动作方向 = 关节运动方向，肌肉缩短 | 实心暖色 + 与运动同向箭头 |
| 离心（eccentric） | 肌肉对抗的方向 = 关节运动方向，肌肉在张力下被拉长 | 条纹或描边暖色 + 与运动反向的“制动”箭头 |
| 等长（isometric） | 关节角度基本不变 | 冷色或网点，不画运动箭头 |

编码方案在项目内固定并写入图例；色盲可读时不只依赖红绿区分。离心不是“放松”，下蹲时股四头肌离心控制屈膝，不能画成被动拉长。

`muscles.json` 中每块肌肉的 `actions` 只列教材常见的主要动作。校验器据此提醒：向心主动肌应能产生该动作，离心主动肌应能产生相反动作。出现警告时核对来源，不为消除警告而改写医学事实。

## 3. 解剖结构在动作中的表达

- **起止点与力线：**肌肉轮廓从真实起点画到真实止点，跨越的关节数正确。双关节肌（股直肌、腘绳肌长头、腓肠肌、肱二头肌、肱三头肌长头）在相邻关节的姿势下长度会变化，画面长度与关节角度一致。
- **肌腱与腱膜：**跟腱、髌韧带、髂胫束、胸腰筋膜等按参考画出走行和附着，不把肌腹直接画到骨面上。
- **骨性标志：**髂前上棘、大转子、髌骨、胫骨粗隆、外踝、肩峰、肩胛下角等用于约束体表投影与姿势，侧视图中前后位置必须核对。
- **深浅层次：**突出深层肌（如腹横肌、肩袖、比目鱼肌）时，用剖切、半透明或剥离示意说明浅层被移除，不能让深层肌“浮”在皮肤表面。
- **关节活动度：**画面角度在正常范围内，并与所述人群和动作一致。需要标注度数时必须有来源 ID；一般示意图不要写出精确角度。
- **体表与比例：**人体比例、肌肉体积和体脂按读者对象设定，健美式夸张造型须在风格说明中写明，不能改变结构关系。

## 4. 力与力矩箭头

| 箭头 | 用途 | 规则 |
|---|---|---|
| 运动箭头（motion） | 节段或关节的运动方向 | 弧形箭头围绕关节轴，方向与本分期 `joint_actions` 一致 |
| 力箭头（force） | 地面反作用力、外负荷、肌力线 | 起点画在作用点，方向与参考一致；必须有来源 ID |
| 力矩箭头（torque） | 净关节力矩 | 只在有生物力学来源时使用，并在图注说明内力矩/外力矩约定 |
| 时序箭头（sequence） | 动作链、分期顺序 | 不暗示未经证实的激活先后 |

箭头长度只在有数据支持时按比例画；示意性箭头在图注标明“非按比例”。不得用箭头把未经证实的“发力顺序”或“代偿链”画成定论。

## 5. 证据选择

| 内容 | 适用来源 |
|---|---|
| 起止点、神经支配、层次 | 解剖学教材与图谱（如 Moore、Gray's、Netter 等合法获取版本）、可追溯三维模型 |
| 关节运动学与肌肉功能 | 运动学/肌动学教材（如 Neumann）、肌肉测试教材（如 Kendall） |
| 某动作中的肌肉激活与时序 | 表面/针极 EMG 研究、系统综述；注意标准化方式（%MVIC）、受试者和负荷 |
| 关节角度、力、力矩 | 运动捕捉与测力台研究、逆动力学研究 |
| 训练与康复建议 | 指南与共识（如 ACSM、NSCA、相关专科学会）、系统综述，按证据等级表述 |

EMG 幅值不等于肌力，不同研究的 %MVIC 不能直接比较大小。单项研究的结论写成“在该研究的受试者中观察到……”。网页健身图、AI 图和社交媒体肌肉图只可用于了解表达方式，不能作为医学证据。

## 6. 常见错误清单

- 把“目标肌”画成唯一工作的肌肉，忽略主要协同肌与稳定肌。
- 下降/下蹲阶段把主动肌标为“拮抗肌放松”，或把离心收缩画成向心。
- 侧视图中标注只能在冠状面或水平面看到的动作，比如膝外翻、骨盆侧倾或旋转。
- 双关节肌长度与关节姿势矛盾，起止点跨错关节。
- 左右侧、支撑腿/摆动腿或动作分期前后不一致。
- 用夸张角度、错误负重姿势或“标准动作”示范存在风险的技术（如负重下脊柱明显屈曲却标为正确）。
- 把个体差异、研究争议或训练流派观点画成普遍规律。

完成后按[质量检查](qa-and-prepress.md)逐图对照，并运行 `scripts/check_movement_spec.py` 检查动作规格。校验通过只说明规格自洽，不代表医学正确。
