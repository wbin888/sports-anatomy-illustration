# 运动损伤机制与康复图示

适用于运动损伤机制图、损伤部位解剖图、预防训练与康复动作示意。按风险等级属于高风险教学内容，须对照[共用医学规则](../SKILL.md#共用医学与进度规则)的精细解剖与康复要求检查。

## 表达原则

- **机制 ≠ 病因定论：**大多数运动损伤为多因素。画面可以展示“常见受伤姿势/负荷模式”，图注写明“常见机制之一”“与风险增加相关”，不画成单一因果链。
- **解剖损伤要具体：**写清结构名称、侧别、部位（近端/远端、止点/肌腹/肌腱结合部）和分级体系来源；不要用一团红色泛指“受伤”。
- **影像与示意分开：**示意图不冒充 MRI/超声表现；真实影像按[生成与资产](generation-and-assets.md#画面检查与修正)去标识化和授权。
- **康复动作是教学示意，不是处方：**不写具体组数、负荷、进阶时间，除非来自明确引用的指南或方案，并注明适用人群；加“请在专业人员指导下进行”类提示。
- **不承诺疗效：**禁止“保证不再受伤”“X 天痊愈”等表述。

## 半透明损伤解剖图

- 医学科普涉及受伤时，必须有一幅能同时看见身体轮廓或相邻组织、关键解剖层次与受累区域的图。可用半透明人体局部、局部透视窗，或可靠解剖图版上叠加局部透明损伤层；半透明指画面内的结构层，不要求透明背景。
- 用淡灰或低饱和色保留定位所需的骨和周围组织，以红或橙半透明层突出有依据的受累结构或附着区。标明视角、侧别、标准解剖名及来源 ID；用图例区分结构、受累区和体表疼痛位置。无证据时不绘制断口、裂隙、分级或具体病变范围。条件允许且对理解有帮助时，同视角对照正常和受伤。
- 解剖母版、损伤高亮及文字标注独立保留，便于更正且不重绘已核结构。需在成品字幕解释“哪一处、是什么结构、图中颜色代表什么”。若缺可靠依据，只交已完成且不受影响的页，明确该损伤图待补证，不以红斑或未核生成图冒充。

## 常见损伤的取证要点

以下只列作图时**必须核对的关系**和常见表达风险，不提供医学结论；具体内容按项目来源确认。

| 主题 | 需核对的结构关系 | 常见表达风险 |
|---|---|---|
| 前交叉韧带（ACL）非接触性损伤 | ACL 起止（股骨外侧髁内侧面 → 胫骨髁间前区）、走行方向；受伤时膝屈曲角度、胫骨前移/旋转、膝外翻的组合 | 只画膝外翻；把所有落地内扣画成必然撕裂 |
| 踝关节内翻扭伤 | 距腓前韧带、跟腓韧带、距腓后韧带的位置与顺序；跖屈内翻位 | 把外侧韧带画到内踝；忽略跖屈位的作用 |
| 腘绳肌拉伤 | 长头/短头、近端肌腱结合部、跑步摆动末期或伸髋屈膝负荷 | 把高风险窗口画成唯一机制；混淆股二头肌长短头 |
| 肩袖病变/肩峰下疼痛 | 冈上肌腱与肩峰、喙肩韧带、肩峰下滑囊的空间关系 | 把“撞击”画成唯一病因；肩袖止点画错结节 |
| 髌腱病 | 髌韧带近端附着（髌骨下极）、跳跃落地负荷 | 与股四头肌腱病混淆；疼痛部位标错 |
| 跟腱病/断裂 | 腓肠肌与比目鱼肌汇合、跟骨结节止点、中段与止点病变区别 | 把比目鱼肌画成不参与跟腱 |
| 肱骨外上髁痛（网球肘） | 桡侧腕短伸肌起点与外上髁关系 | 只写“网球肘”而不说明伸肌总腱 |

## 预防与康复示意

1. 先确认来源类型：临床指南、共识声明、系统综述或具体研究方案，记录适用人群与阶段。
2. 动作示范按[动作分析](movement-analysis.md)写 spec，正确与错误姿势分开排版，错误示范用统一的警示标识。
3. 疼痛标识（如闪电符号）表示症状位置时须与解剖部位一致，不暗示损伤分级。
4. 涉及器械、贴扎、支具时核对佩戴方向和侧别，并说明“示意，不替代专业评估”。

交付状态仍分开记录：制作完成、医学图文对照、人工审签。缺少人工审签时标为“制作完成，医学待审”。
