# README 配图参考对照表

含医学内容的配图为简化示意，非诊断图像、技术处方或测量结果。当前状态：**制作完成，医学待审**。

| 来源 ID | 原始出处与定位 | 核对范围 |
|---|---|---|
| SEER | 美国国家癌症研究所（NCI），[Structure of Skeletal Muscle](https://training.seer.cancer.gov/anatomy/muscular/structure.html)，正文中的 [结构图版](https://training.seer.cancer.gov/images/anatomy/muscular/muscle_structure.jpg) | 实际查看原图并与新图对照，只核对通用骨骼肌的三个嵌套层次。原图未输入生图工具或收录进仓库。 |
| SQ22 | [Determining concentric and eccentric force–velocity profiles during squatting](https://pmc.ncbi.nlm.nih.gov/articles/PMC8854263/)，引言中关于下蹲、起身阶段的说明 | 核对阶段区分。不从插画推断关节角度、肌电或负荷。 |

| 文件／位置 | 解剖名称或呈现对象 | 视角／层次与支持范围 | 来源 |
|---|---|---|---|
| teaching-example.webp／左 | 骨骼肌（skeletal muscle） | 通用整肌斜切示意，切面包含多个肌束；不指定人体部位或侧别 | SEER |
| teaching-example.webp／中 | 肌束（muscle fascicle） | 单个肌束斜切放大示意，包含多条肌纤维 | SEER |
| teaching-example.webp／右 | 肌纤维（muscle fiber） | 单条圆柱状肌纤维放大示意；不标注细胞器、膜层或微细结构 | SEER |
| squat-phases.webp／左、右 | 杠铃后蹲的两个时点 | 外观斜侧视，左图接近下蹲底部、右图处于起身途中；无肌肉图层 | SQ22 |

科普漫画是虚构的膝前不适咨询场景，不显示解剖切面或给出诊断。横幅、科研主题插画和流程图为展示配图；流程道具上的图形不用于解剖教学，科研插画的屏幕图案不是实验数据。科研示例的正式机制关系与文献保留在 [research-example.mechanism-graph.json](research-example.mechanism-graph.json)。

旧版 SVG 的来源映射可在 [历史版本](https://github.com/wbin888/sports-anatomy-illustration/blob/333d7f412ef3e9837aba7848a22c033c4e69c375/docs/examples/references.md) 查看，不用于给新版图作证。
